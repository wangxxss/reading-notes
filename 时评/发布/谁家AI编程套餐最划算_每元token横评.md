# 谁家 AI 编程套餐最划算？用「每元能买多少 token」量一遍就清楚了

现在挑一个 AI 编程套餐，比挑手机套餐还累。

光我手头这份数据，就有 8 家厂商、34 个套餐，价格从 ¥29 一路飙到 ¥1398。有的按「请求次数」卖，有的按「token」卖，有的还分 5 小时、周、月三个额度窗口。每家话术都讲得天花乱坠，横着比根本比不动。

那就换把尺子：**同样花一块钱，谁给你的 token 多？**

把所有套餐的价格和额度一除，得到一个「每元 token 数」，单位拉齐了，谁贵谁便宜一目了然。我用这把尺子量了一遍，结论是——**最便宜的，往往不是你最该买的。**

## 先把这把尺子说诚实

量之前，得先承认这把尺子有个坑，否则容易被数字骗。

市面上的套餐分两种计费口径：

- **Token Plan**：厂商明明白白告诉你这个月给多少 token，用完就停。这是**硬额度**。
- **Coding Plan**：厂商只告诉你「5 小时多少次请求」，至于折合多少 token，是按一个用量样本**估算**出来的。这是**理论上限**。

这俩混在一起排名，会出大错。Coding Plan 那串漂亮数字是「理论上你最多能薅到这么多」，真拿 Agent 跑复杂项目，缩水得厉害。所以下面我**分开排**：先看最实在的 Token Plan，再看要打折扣看的 Coding Plan。

（另外，腾讯、百度、京东这些厂商因为缺用量样本，这次没进榜，别当成全行业排名。）

看出门道了吗？

**MiniMax 一骑绝尘**，每元一千多万 token，是第二名的两倍还多。**国外的 Claude、Codex 只有买到最高倍数档（*20）才追上来**，平时的入门档也就两三百万。**最惨的是字节方舟的 Token Plan，每元只有 55 万**——比 Claude 还贵，垫底。

这里就有个反差：字节方舟的 **Coding Plan** 便宜得很（下面会看到），但它的 **Token Plan** 却贵得离谱。同一家厂商，两种口径价差几十倍。所以买之前一定要看清楚你买的是哪种。

## 顺手戳破两个幻觉

**幻觉一：国内比国外便宜「几十倍」。**

不对。拿可比的 Token Plan 看，国内最猛的 MiniMax（一千多万）也就是 Claude/Codex（两三百万）的**四五倍**，不是几十倍。那个「几十倍」的说法，是有人拿**已经停售**的 MiniMax Coding Plan 估算值（四五千万）去比 Claude——拿打折清仓价比原价，当然吓人。

**幻觉二：最划算的套餐，你现在还能买到。**

不能。性价比榜上最炸裂的 MiniMax Coding Plan——Starter、Plus、Max、极速版——**全线已停售**。能薅的羊毛，厂商自己先收走了。这不是巧合：早期为抢用户疯狂补贴，用户养起来了，补贴就开始退坡。你现在能买到的，已经是「正常价」了。

## 所以，最便宜 ≠ 最该买

性价比只是**一个**维度。一个每元给你两千万 token 的套餐，如果模型写出来的代码一塌糊涂、高峰期还限速、过两个月就停售——那它再便宜也是坑。

真正该一起看的还有三件事：**模型到底好不好用、高峰会不会卡、这套餐能不能让你长期稳定续上。**

给三类人的实在建议：

- **省钱党**：MiniMax 的在售 Token Plan，每元 token 全场最高，¥49 的 Plus 就能跑很多。预算有限闭眼选。
- **求稳党**：智谱、阿里这类大厂的在售套餐，性价比中上，模型成熟、供应稳定，不用担心明天就停售。
- **重度 Agent 党**：你每天烧的是上亿 token，别只盯单价。算清楚日均用量，再决定堆高倍档还是按量买——这个量级，没有真正「便宜」的方案，只有「烧多烧少」。

挑套餐这事，别被某一个漂亮数字带着走。先问自己用量多大、对模型挑不挑、能不能接受随时停售，再回头看这张表，答案就清楚了。
