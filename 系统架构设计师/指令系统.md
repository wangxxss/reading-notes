## 1. 指令系统概述

### 1.1 指令与指令系统

**指令**是计算机执行某种操作的命令，包括操作码和地址码。

**指令系统**是计算机所能执行的全部指令集合，决定了计算机的基本功能，是计算机硬件与软件之间的接口。

### 1.2 指令的基本格式

```
┌──────────────────────────────────────┐
│  操作码字段 (OP)  │  地址码字段 (A)  │
└──────────────────────────────────────┘
```

| 字段 | 说明 |
|------|------|
| 操作码 (OP) | 指定操作的性质和功能，如加、减、传送、跳转等 |
| 地址码 (A) | 指定操作数的地址或操作数本身 |

### 1.3 指令执行过程

```
取指(Fetch) → 译码(Decode) → 执行(Execute) → 访存(Memory) → 写回(Writeback)
```

## 2. 指令格式

### 2.1 按地址码数目分类

| 类型 | 地址码数目 | 指令格式 | 特点 |
|------|------------|----------|------|
| **零地址指令** | 0 | OP | 操作数隐含在栈顶或累加器中，如入栈、出栈、PUSH、POP |
| **一地址指令** | 1 | OP A1 | 操作数隐含在AC（累加器）中，如INC、DEC |
| **二地址指令** | 2 | OP A1 A2 | 最常见格式，A1为目的操作数，A2为源操作数 |
| **三地址指令** | 3 | OP A1 A2 A3 | 最完整形式，A1为目的操作数 |

**考试重点：** 地址码数目越多，指令越长，占用存储空间越大。

### 2.2 指令字长

| 类型 | 说明 |
|------|------|
| 固定字长 | 所有指令长度相同，如RISC架构 |
| 可变字长 | 指令长度随地址码数目变化，如CISC架构 |

**考试重点：**
- 指令字长 = 操作码长度 + 地址码长度 × 地址码个数
- 指令字长一般取字节的整数倍

### 2.3 操作数类型

| 类型 | 示例 | 说明 |
|------|------|------|
| 立即数 | #100 | 指令中包含的常数 |
| 寄存器 | R1 | 通用寄存器编号 |
| 内存地址 | [1000] | 主存单元地址 |
| 复合类型 | [R1+100] | 寄存器相对寻址 |

## 3. 寻址方式

### 3.1 寻址方式分类表

| 寻址方式 | 有效地址 (EA) | 说明 | 速度 |
|----------|---------------|------|------|
| **立即寻址** | 操作数在指令中 | 最快，但修改不灵活 | ★★★★★ |
| **直接寻址** | EA = A | 地址在指令中，一次访存 | ★★★★ |
| **间接寻址** | EA = (A) | 地址在内存中，多次访存 | ★★ |
| **寄存器寻址** | EA = R | 操作数在寄存器中 | ★★★★★ |
| **寄存器间接寻址** | EA = (R) | 操作数地址在寄存器中 | ★★★ |
| **相对寻址** | EA = PC + A | 用于分支跳转 | ★★★★ |
| **基址寻址** | EA = BR + A | 基址寄存器+偏移 | ★★★ |
| **变址寻址** | EA = IX + A | 变址寄存器+偏移 | ★★★ |

### 3.2 寻址方式详解

#### 3.2.1 立即寻址

```assembly
MOV AX, #100    ; 将常数100送入AX
```

**特点：** 操作数直接在指令中，取指后即得到操作数，无需访存。

**优点：** 最快
**缺点：** 操作数不能修改，灵活性差

#### 3.2.2 直接寻址

```assembly
MOV AX, [1000]  ; 将地址1000的内容送入AX
```

**特点：** 指令中给出操作数的内存地址。

**优点：** 简单
**缺点：** 地址固定，修改不灵活

#### 3.2.3 间接寻址

```assembly
MOV AX, [[1000]] ; 先访问地址1000得到真正地址，再访问
```

**特点：** 指令中给出地址的地址，需要多次访存。

**优点：** 灵活性高，可实现共享
**缺点：** 速度慢

#### 3.2.4 寄存器寻址

```assembly
MOV AX, BX      ; 将BX的内容送入AX
```

**特点：** 操作数在寄存器中。

**优点：** 速度最快
**缺点：** 寄存器数量有限

#### 3.2.5 寄存器间接寻址

```assembly
MOV AX, [BX]    ; BX中存放地址，取该地址的内容
```

**特点：** 寄存器中存放操作数的地址。

#### 3.2.6 相对寻址

```assembly
JMP #50         ; PC = PC + 50
```

**特点：** 有效地址 = PC当前值 + 位移量A

**用途：** 常用于分支指令和程序转移

#### 3.2.7 基址寻址

```assembly
MOV AX, [BR+100]; 有效地址 = 基址寄存器 + 位移量
```

**特点：** 基址寄存器内容不变，位移量可变

**用途：** 支持程序重定位

#### 3.2.8 变址寻址

```assembly
MOV AX, [IX+100]; 有效地址 = 变址寄存器 + 位移量
```

**特点：** 变址寄存器内容可变，基址固定

**用途：** 用于数组处理，如遍历数组元素

### 3.3 寻址方式速度比较

```
立即寻址 > 寄存器寻址 > 直接寻址 > 寄存器间接寻址 > 间接寻址
   最快                                              最慢
```

**考试重点：** 记住这个速度排序，几乎是每年必考的知识点。

### 3.4 寻址方式对比表

| 寻址方式 | 访存次数 | 灵活性 | 典例用途 |
|----------|----------|--------|----------|
| 立即寻址 | 0 | 差 | 常量定义 |
| 直接寻址 | 1 | 差 | 固定变量 |
| 间接寻址 | ≥2 | 好 | 指针操作 |
| 寄存器寻址 | 0 | 中 | 通用计算 |
| 寄存器间接寻址 | 1 | 好 | 指针遍历 |
| 相对寻址 | 0 | 好 | 程序跳转 |
| 基址寻址 | 1 | 好 | 程序重定位 |
| 变址寻址 | 1 | 好 | 数组访问 |

## 4. CISC与RISC技术

### 4.1 基本概念

| 类型 | 全称 | 含义 |
|------|------|------|
| **CISC** | Complex Instruction Set Computer | 复杂指令系统计算机 |
| **RISC** | Reduced Instruction Set Computer | 精简指令系统计算机 |

### 4.2 CISC与RISC对比表

| 特征 | CISC | RISC |
|------|------|------|
| **指令条数** | 多（>200条） | 少（<100条） |
| **指令长度** | 变长 | 定长 |
| **执行时间** | 不等，单周期或多周期 | 大多单周期 |
| **寻址方式** | 多种（>10种） | 少（<5种） |
| **通用寄存器** | 少（<20个） | 多（>32个） |
| **译码方式** | 微程序控制 | 硬连线控制 |
| **指令格式** | 不规整 | 规整（三地址格式） |
| **编译器** | 复杂 | 简单 |
| **LOAD/STORE指令** | 无独立 | 有独立（需访存指令） |
| **流水线支持** | 难实现 | 易实现 |

### 4.3 典型代表

| CISC | RISC |
|------|------|
| x86（Intel） | ARM |
| VAX | MIPS |
| IBM System/360 | PowerPC |
| | SPARC |

### 4.4 RISC的关键技术

1. **寄存器窗口优化技术**
   - 提高寄存器利用效率
   - 减少访存次数

2. **流水线优化**
   - 指令流水线
   - 延迟加载（Delay Slot）

3. **硬连线控制**
   - 指令执行速度更快
   - 译码简单

4. **LOAD/STORE架构**
   - 只有LOAD和STORE指令访问内存
   - 其他指令在寄存器间完成

### 4.5 考试重点速记

**CISC特点：** 多、全、变、慢
- 指令多、功能全、变长、慢

**RISC特点：** 少、定、单、快
- 指令少、定长、单周期、快

**一句话记忆：** RISC是"精简版"的CISC，为了解决CISC的缺点而设计。

## 5. 指令流水线

### 5.1 流水线基本概念

**流水线**是将指令执行过程分为多个阶段，每个阶段由专用硬件执行，实现指令并行。

**流水线周期：** 各阶段中最长执行时间

### 5.2 经典五段流水线

```
┌─────┬─────┬─────┬─────┬─────┐
│ 取指 │ 译码 │ 执行 │ 访存 │ 写回 │
│ IF  │ ID  │ EX  │ MEM │ WB  │
└─────┴─────┴─────┴─────┴─────┘
```

### 5.3 流水线性能指标

#### 5.3.1 吞吐率 (Throughput Rate)

$$TP = \frac{n}{T_k} = \frac{n}{(k+n-1)\Delta t}$$

其中：
- n：任务数
- k：流水级数
- Δt：时钟周期

**最大吞吐率：** $TP_{max} = \frac{1}{\Delta t}$

#### 5.3.2 加速比 (Speedup Ratio)

$$S = \frac{T_0}{T_k} = \frac{kn}{k+n-1}$$

当 n >> k 时，$S ≈ k$

#### 5.3.3 效率 (Efficiency)

$$E = \frac{n \cdot k \cdot \Delta t}{(k+n-1)\Delta t \cdot k} = \frac{n}{k+n-1}$$

**考试重点：** 当 n → ∞ 时，效率趋近于 100%，但永远达不到。

### 5.4 流水线相关问题

| 问题类型 | 描述 | 解决方案 |
|----------|------|----------|
| **结构冒险** | 硬件资源冲突 | 增加资源（如指令和数据Cache分开） |
| **数据冒险** | 数据依赖（RAW/WAR/WAR） | 前推(Forwarding)、暂停(Stalling) |
| **控制冒险** | 分支指令影响 | 分支预测(Static/Dynamic)、延迟分支 |

#### 数据冒险类型

| 类型 | 英文 | 说明 |
|------|------|------|
| 读后写 | RAW (Read After Write) | 真实数据冒险 |
| 写后读 | WAR (Write After Read) | 反相关 |
| 写后写 | WAW (Write After Write) | 输出相关 |

**考试重点：** 流水线中的数据相关主要是RAW（读后写），也叫"真数据相关"。

### 5.5 超标量流水线

| 指标 | 标量流水线 | 超标量流水线 |
|------|------------|--------------|
| 度 (Issue) | 1条/周期 | 多条/周期 |
| CPI | ≥1 | <1 |
| 特点 | 顺序执行 | 乱序执行 |

## 6. 真题解析与考点总结

### 6.1 高频考点速查表

| 考点 | 频率 | 重要程度 |
|------|------|----------|
| 寻址方式速度比较 | ★★★ | 必须掌握 |
| CISC vs RISC | ★★★ | 必须掌握 |
| 指令格式（地址码数目） | ★★ | 理解记忆 |
| 流水线公式 | ★★ | 计算题 |
| 数据冒险类型 | ★★ | 理解记忆 |

### 6.2 寻址方式速度排序（必背）

```
立即寻址 = 寄存器寻址 > 直接寻址 > 寄存器间接寻址 > 间接寻址
   最快（0次访存）                              最慢（2次访存）
```

### 6.3 CISC与RISC核心区别（必背）

| 对比项 | CISC | RISC |
|--------|------|------|
| 指令数 | >200 | <100 |
| 长度 | 变长 | 定长 |
| 执行 | 多周期 | 单周期 |
| 寄存器 | 少 | 多 |
| 译码 | 微程序 | 硬连线 |

### 6.4 易错点总结

1. **寻址方式：** 寄存器间接寻址需要1次访存，不是0次
2. **间接寻址：** 需要2次访存，比寄存器间接寻址更慢
3. **CISC/RISC：** x86是CISC，ARM是RISC
4. **流水线：** 加速比最大为流水级数k
5. **数据冒险：** RAW是唯一不能消除的（真相关）

### 6.5 综合知识答题技巧

**技巧1：排除法**
- 先排除明显错误的选项
- 注意"绝对化"表述通常是错的

**技巧2：对比法**
- 题目问"最快"，找访存次数最少的
- 题目问"最慢"，找访存次数最多的

**技巧3：关键词法**
- 看到"指令少、定长"选RISC
- 看到"指令多、变长"选CISC
