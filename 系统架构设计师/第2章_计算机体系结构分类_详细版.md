## 2.1 体系结构的基本概念

### 2.1.1 什么是计算机体系结构

**定义：** 计算机体系结构是指计算机的概念性结构和功能属性，包括指令集、数据类型、存储器寻址方式、I/O机理等。

**两个层次的理解：**

| 层次 | 说明 | 关注点 |
|------|------|--------|
| 体系结构 | 程序员看到的计算机属性 | 指令系统、数据表示、寻址方式 |
| 组织实现 | 具体硬件实现 | 微架构、逻辑设计、硬件细节 |

**经典案例：** x86和ARM
- **x86体系结构**：复杂指令集（CISC），面向PC和服务器
- **ARM体系结构**：精简指令集（RISC），面向移动设备和嵌入式

**考试重点：** 体系结构是程序员看到的抽象层，组织实现是硬件的具体实现。同一体系结构可以有不同的实现（如Intel i3/i5/i7都是x86架构的不同实现）。

### 2.1.2 计算机体系结构的发展历程

```
第一代（1940s-1950s）
├── 电子管计算机
├── 真空管技术
├── 机器语言编程
└── 无操作系统

第二代（1950s-1960s）
├── 晶体管计算机
├── 出现汇编语言和高级语言（FORTRAN）
├── 早期操作系统
└── 批处理系统

第三代（1960s-1970s）
├── 集成电路计算机
├── 微程序控制技术
├── 流水线和Cache概念出现
└── 多道程序设计

第四代（1970s-至今）
├── 大规模和超大规模集成电路
├── RISC和CISC并行发展
├── 并行处理技术成熟
└── 多核处理器普及
```

## 2.2 Flynn分类法（最重要）

### 2.2.1 分类依据

**M.J.Flynn于1966年提出**，根据**指令流**和**数据流**两个维度进行分类：

| 术语 | 全称 | 含义 |
|------|------|------|
| 指令流（IS） | Instruction Stream | 处理器执行的指令序列 |
| 数据流（DS） | Data Stream | 处理的数据序列 |
| 控制流（CS） | Control Stream | 指令流的控制机制 |

### 2.2.2 四种基本分类（考试核心）

| 分类 | 全称 | 指令流 | 数据流 | 代表架构 | 典型代表 |
|------|------|--------|--------|----------|----------|
| **SISD** | Single Instruction Single Data | 1 | 1 | 传统冯·诺依曼机 | 早期大型机、绝大多数单核CPU |
| **SIMD** | Single Instruction Multiple Data | 1 | 多 | 并行处理机 | GPU、Intel SSE/AVX、阵列处理器 |
| **MISD** | Multiple Instruction Single Data | 多 | 1 | 多处理器特殊结构 | 理论模型（较少实际实现） |
| **MIMD** | Multiple Instruction Multiple Data | 多 | 多 | 多处理器系统 | 多核CPU、集群服务器、分布式系统 |

### 2.2.3 各类详解

#### （1）SISD - 单指令流单数据流

**结构特征：**
```
┌─────────────────────────────┐
│        控制单元 (CU)         │──→ 控制信号
└─────────────────────────────┘
              ↓
┌─────────────────────────────┐
│        处理器单元 (PU)       │──→ 处理数据
└─────────────────────────────┘
              ↓
┌─────────────────────────────┐
│         存储器 (Memory)       │←── 单一数据流
└─────────────────────────────┘
```

**特点：**
- 一次执行一条指令
- 一次处理一个数据
- 传统单核处理器的工作方式
- 代表：Intel Core i7、AMD Ryzen等单核模式

**考试记忆：** "**S**ingle **I**nstruction, **S**ingle **D**ata" - 一对一

---

#### （2）SIMD - 单指令流多数据流

**结构特征：**
```
┌─────────────────────────────┐
│        控制单元 (CU)         │──→ 同一指令流
└─────────────────────────────┘
         ↓ ↓ ↓ ↓
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │PU 1│ │PU 2│ │PU 3│ │PU 4│
    └────┘ └────┘ └────┘ └────┘
         ↓ ↓ ↓ ↓
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │P1  │ │P2  │ │P3  │ │P4  │ ← 不同数据
    └────┘ └────┘ └────┘ └────┘
```

**特点：**
- 一条指令同时处理多个数据
- 适合数据并行操作
- 典型应用：**向量处理器、GPU、图像处理**

**典型代表：**
| 代表 | 说明 |
|------|------|
| GPU | 数千个处理核心，SIMD的代表 |
| Intel AVX/SSE | 多媒体指令集 |
| 向量处理器 | Cray超级计算机 |

**考试记忆：** "**S**ingle **I**nstruction, **M**ultiple **D**ata" - 一对多

---

#### （3）MISD - 多指令流单数据流

**结构特征：**
```
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │CU 1│ │CU 2│ │CU 3│ │CU 4│ ← 多条指令
    └────┘ └────┘ └────┘ └────┘
         ↓ ↓ ↓ ↓
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │PU 1│ │PU 2│ │PU 3│ │PU 4│
    └────┘ └────┘ └────┘ └────┘
         ↓ ↓ ↓ ↓
    ┌─────────────────────────────┐
    │         单一数据流            │
    └─────────────────────────────┘
```

**特点：**
- 多条指令处理同一数据
- 理论意义大于实践意义
- 实际中很少有真正实现

**考试重点：** MISD是**理论上存在但实际很少实现**的结构，考试常作为干扰选项。

**考试记忆：** "**M**ultiple **I**nstruction, **S**ingle **D**ata" - 多对一

---

#### （4）MIMD - 多指令流多数据流

**结构特征：**
```
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │CU 1│ │CU 2│ │CU 3│ │CU 4│ ← 多指令流
    └────┘ └────┘ └────┘ └────┘
         ↓ ↓ ↓ ↓
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │PU 1│ │PU 2│ │PU 3│ │PU 4│
    └────┘ └────┘ └────┘ └────┘
         ↓ ↓ ↓ ↓
    ┌────┐ ┌────┐ ┌────┐ ┌────┐
    │M1  │ │M2  │ │M3  │ │M4  │ ← 多数据流
    └────┘ └────┘ └────┘ └────┘
```

**特点：**
- 每个处理器独立执行自己的指令
- 每个处理器处理自己的数据
- 最符合多核处理器的工作方式
- 典型应用：**多核CPU、分布式计算、集群**

**分类：**
| 类型 | 说明 | 例子 |
|------|------|------|
| 共享内存MIMD | 所有处理器共享同一物理内存 | 多核CPU（SMP） |
| 分布式内存MIMD | 每个处理器有独立内存 | 集群计算机 |

**考试记忆：** "**M**ultiple **I**nstruction, **M**ultiple **D**ata" - 多对多

### 2.2.4 Flynn分类法总结表

```
┌────────┬──────────┬─────────┬────────────────────────┐
│  分类   │ 指令流    │ 数据流  │         说明          │
├────────┼──────────┼─────────┼────────────────────────┤
│  SISD  │    1     │    1    │  单处理器计算机         │
│  SIMD  │    1     │   多    │  并行处理器、GPU        │
│  MISD  │   多     │    1    │  理论模型（少实现）     │
│  MIMD  │   多     │   多    │  多处理器/多核系统      │
└────────┴──────────┴─────────┴────────────────────────┘
```

**考试重点：** Flynn分类法是每年必考的知识点，必须熟记四种分类的结构特点。

## 2.3 冯氏分类法

### 2.3.1 分类依据

由**冯·泽尼克（Zeigler）** 提出，用**数据流和指令流的吹口**来分类。

### 2.3.2 分类体系

| 类型 | 说明 |
|------|------|
| **字片并行（Word Slice）** | 一条指令处理多个字 |
| **位片并行（Bit Slice）** | 多条指令处理同一个字的多个位 |

**与Flynn分类的对应关系：**
```
冯氏分类 ←→ Flynn分类
字片并行 ←→ SIMD
位片并行 ←→ MIMD
```

**考试重点：** 冯氏分类法在考试中出现频率较低，了解即可。

---

## 2.4 其他分类法

### 2.4.1 Handler分类法

根据**计算机的并行度和流水线**进行分类。

**表示形式：** t(系统级) × p(处理机级) × d(功能部件级)

**例：** t3 × p7 × d2 表示系统级3并行、处理机级7并行、功能部件级2并行

### 2.4.2 Kuck分类法

与Flynn类似，用**指令流和数据流**分类，但增加了**控制流**维度。

| 分类 | 说明 |
|------|------|
| SJIS | 单指令流单数据流（SISD） |
| MJIS | 多指令流单数据流（MISD） |
| SIMS | 单指令流多数据流（SIMD） |
| MIMS | 多指令流多数据流（MIMD） |

**考试重点：** 其他分类法在考试中考查频率很低，重点掌握Flynn分类法即可。

## 2.5 处理器性能提升技术

### 2.5.1 时间重叠（Time Overlapping）

**原理：** 将一个任务分解为多个阶段，每个阶段由不同的专用部件处理，不同任务的阶段并行执行。

```
任务A：  [阶段1] → [阶段2] → [阶段3]
任务B：           [阶段1] → [阶段2] → [阶段3]
任务C：                    [阶段1] → [阶段2] → [阶段3]

时间：   t1    t2    t3    t4    t5    t6    t7
```

**代表技术：流水线技术**

**考试重点：** 时间重叠是**流水线技术**的理论基础。

---

### 2.5.2 资源重复（Resource Replication）

**原理：** 在重复设置多个同样的硬件资源，让它们并行工作。

```
        ┌────────┐
        │  控制器  │
        └────┬───┘
     ┌───────┼───────┐
     ↓       ↓       ↓
┌────────┐┌────────┐┌────────┐
│处理器1 ││处理器2 ││处理器3 │
└────────┘└────────┘└────────┘
     ↓       ↓       ↓
┌────────┐┌────────┐┌────────┐
│ 内存1  ││ 内存2  ││ 内存3  │
└────────┘└────────┘└────────┘
```

**代表技术：**
- 多处理器系统（SMP）
- 多核处理器
- RAID磁盘阵列

**考试重点：** 资源重复是**并行处理**和**多核技术**的理论基础。

---

### 2.5.3 资源共享（Resource Sharing）

**原理：** 多个任务分时共享同一个硬件资源，通过调度提高资源利用率。

**代表技术：**
- 分时操作系统
- 虚拟化技术
- 云计算资源调度

**特点：**
- 成本低
- 利用率高
- 可能产生竞争

### 2.5.6 三种技术对比

| 技术 | 原理 | 目标 | 代表技术 |
|------|------|------|----------|
| 时间重叠 | 任务阶段并行 | 速度 | 流水线 |
| 资源重复 | 硬件复制并行 | 吞吐 | 多核、集群 |
| 资源共享 | 分时复用 | 利用率 | 虚拟机、分时系统 |

---

## 2.6 并行处理技术

### 2.6.1 并行性的层次

| 层次 | 说明 | 例子 |
|------|------|------|
| 指令内部并行 | 一条指令内部的微操作并行 | 超标量、流水线 |
| 指令级并行 | 多条指令同时执行 | 流水线、多发射 |
| 任务级并行 | 多个任务/进程并行 | 多核、分布式 |
| 数据级并行 | 多个数据元素并行操作 | SIMD、GPU |
| 线程级并行 | 多个线程同时执行 | 多线程、SMT |

### 2.6.2 多核处理器

**定义：** 在单个芯片上集成多个独立的处理器核心。

**结构示意：**
```
┌─────────────────────────────────────┐
│            处理器芯片                │
│  ┌─────────┐  ┌─────────┐          │
│  │  核心1   │  │  核心2   │          │
│  │(Core 1) │  │(Core 2) │          │
│  └─────────┘  └─────────┘          │
│  ┌─────────┐  ┌─────────┐          │
│  │  核心3   │  │  核心4   │          │
│  │(Core 3) │  │(Core 4) │          │
│  └─────────┘  └─────────┘          │
│  ┌─────────────────────────┐      │
│  │       共享Cache          │      │
│  └─────────────────────────┘      │
│  ┌─────────────────────────┐      │
│  │       内存控制器         │      │
│  └─────────────────────────┘      │
└─────────────────────────────────────┘
```

**多核与多线程的区别：**

| 特性 | 多核 | 多线程 |
|------|------|--------|
| 核心数 | 多个物理核心 | 单个核心虚拟多个 |
| 资源 | 每个核心独立资源 | 共享核心资源 |
| 并行性 | 真正并行 | 伪并行（交替执行） |
| 性能提升 | 显著 | 有限 |

**考试重点：** 多核处理器属于**MIMD**分类（每个核心独立执行指令流）。

### 2.6.3 向量处理器

**定义：** 专门用于处理向量（数组）运算的处理器。

**特点：**
- 单条指令操作多个数据（SIMD典型代表）
- 适用于科学计算、图像处理
- 代表：Cray-1、 NEC SX系列

### 2.6.4 GPU与CPU的区别

| 特性 | CPU | GPU |
|------|-----|-----|
| 设计目标 | 通用计算 | 图形/并行计算 |
| 核心数 | 少（4-64） | 多（数百-数千） |
| 核心复杂度 | 复杂（强分支预测） | 简单（专注于计算） |
| 缓存 | 大而复杂 | 小而简单 |
| 并行模式 | 多核MIMD | 众核SIMD |
| 典型代表 | Intel i7, AMD Ryzen | NVIDIA Tesla, AMD Radeon |

### 2.7.3 典型例题解析

**【例题1】Flynn分类法中，SIMD是指？**

A. 单指令流、单数据流
B. 单指令流、多数据流
C. 多指令流、单数据流
D. 多指令流、多数据流

**答案：B**

**解析：** SIMD = Single Instruction Multiple Data，即单指令流、多数据流。

---

**【例题2】以下哪种计算机结构最适合数据并行计算？**

A. SISD
B. SIMD
C. MISD
D. MIMD

**答案：B**

**解析：** 数据并行需要对多个数据执行相同操作，SIMD结构一条指令同时处理多个数据，非常适合数据并行。GPU就是SIMD的典型代表。

---

**【例题3】多核处理器属于Flynn分类法中的哪种类型？**

A. SISD
B. SIMD
C. MISD
D. MIMD

**答案：D**

**解析：** 多核处理器每个核心独立执行自己的指令流和数据流，属于MIMD（多指令流、多数据流）。

---

**【例题4】关于MISD的说法正确的是？**

A. 有实际产品实现
B. 多指令流处理单一数据流
C. 是最常见的计算机结构
D. 流水线计算机可归为MISD

**答案：B**

**解析：** MISD（多指令流、单数据流）是理论模型，实际很少有真正实现。但要注意，流水线计算机有时被归为MISD的争议讨论。

---

**【例题5】流水线技术体现了哪种性能提升原理？**

A. 时间重叠
B. 资源重复
C. 资源共享
D. 指令并行

**答案：A**

**解析：** 流水线通过将任务分成多个阶段，让不同任务的阶段并行执行，体现了时间重叠原理。

## 2.8 备考建议

1. **以Flynn分类为核心**：这是考试考查最多的知识点

3. **结合实际例子**：每个分类对应一个实际产品，加深理解
4. **区分易混点**：MISD是理论模型、MIMD是多核/集群、SIMD是GPU
